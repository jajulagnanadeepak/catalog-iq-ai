# CatalogIQ AI

Build a modern AI-powered e-commerce frontend called "CatalogIQ AI" using React, Vite, TypeScript, Tailwind CSS, shadcn/ui, React Router, TanStack Query, and Axios.

Theme:

Modern AI SaaS with a clean, premium, responsive UI (Blue, White, Dark Slate). Support Dark Mode.

Create these pages:

- Landing Page

- Login & Signup

- Dashboard

- Semantic Search

- Product Details

- AI Shopping Copilot (Chat UI)

- AI Stylist

- Budget Optimizer

- Seasonal Recommendations

- Visual Search (Image Upload)

- User Profile

Create reusable components:

Navbar, Sidebar, Product Card, Search Bar, Recommendation Card, Filters, Loading Skeletons, Toasts, Footer, Pagination.

Assume backend APIs already exist. Create an API service layer with placeholders for:

GET /products

POST /search

GET /recommend

POST /intent

POST /stylist

POST /budget

POST /copilot

POST /visual-search

GET /seasonal

Do NOT generate backend code or AI logic. Focus only on a production-ready frontend with a clean folder structure, reusable components, responsive design, and smooth animations.
